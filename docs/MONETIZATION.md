# OpenClaw 招标雷达 - 商业化方案 (MONETIZATION)

## 商业模式

**订阅制SaaS**：用户按月/年付费，获取招标情报订阅服务

## 定价策略

### 免费版 (Free)
- **价格**：¥0
- **内容**：每日3条精选招标
- **交付**：飞书/邮件文字版
- **目标**：获客引流，用户体验

### 标准版 (Standard) ⭐ 主推
- **价格**：¥99/月 或 ¥999/年（省¥189）
- **内容**：
  - 每日10条精选招标
  - 每周深度分析报告
  - 基础筛选（地区+行业）
- **交付**：飞书/邮件 + PDF报告
- **目标**：主力收入来源

### 高级版 (Premium)
- **价格**：¥299/月 或 ¥2999/年（省¥589）
- **内容**：
  - 每日全量招标（50+条）
  - 每周深度报告 + 月度趋势
  - 定制关键词监控
  - 紧急提醒（微信/短信）
  - API接口访问
- **交付**：多渠道 + API
- **目标**：高价值客户，提升客单价

## 获客渠道

### 1. 闲鱼 (低成本试错)
- **商品标题**：「招标信息监控 每日推送 政府采购商机」
- **价格锚点**：¥99/月
- **引流话术**：先免费试用3天，满意再付费
- **预期转化**：2-5%

### 2. 知乎 (内容获客)
- **回答领域**：政府采购、招投标、销售技巧
- **内容形式**：干货回答 + 软广
- **引流路径**：签名区 → 公众号/飞书
- **预期转化**：1-3%

### 3. 即刻/小红书 (年轻群体)
- **内容**：招标信息差、赚钱机会
- **形式**：截图展示每日精选
- **引流**：私信/群聊

### 4. 微信朋友圈 (私域)
- **内容**：每日精选招标截图
- **信任建立**：7天免费试阅
- **转化**：朋友圈 → 私聊 → 付费

### 5. 老用户转介绍
- **激励**：推荐1人得1个月免费
- **目标**：20%新用户来自转介绍

## 收费方式（MVP阶段）

### 阶段1：手动收款 (Day 1-30)

**流程**：
1. 用户填写表单（飞书/金数据）
2. 用户支付宝/微信转账
3. 人工确认到账
4. 手动添加到 subscribers 表
5. 开始推送

**优点**：
- 无需开发支付接口
- 资金安全可控
- 快速验证需求

**缺点**：
- 人工成本
- 不适合规模化

### 阶段2：半自动收款 (Day 31-90)

**流程**：
1. 接入支付宝当面付/微信收款码
2. 用户扫码支付
3. 半自动确认（支付宝有webhook）
4. 自动开通服务

### 阶段3：全自动订阅 (Day 90+)

**流程**：
1. 接入支付宝/微信自动扣款
2. 用户授权订阅
3. 每月自动扣费
4. 失败自动提醒

## 风险控制

### 退款政策
- **7天无理由退款**：增强信任
- **未推送全额退**：未使用服务可退
- **按比例退**：中途取消按剩余天数退

### 坏账控制
- MVP阶段手动收款，零坏账
- 自动扣费阶段，设置扣费失败提醒
