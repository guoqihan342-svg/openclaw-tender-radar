## 一、Logo设计

### 1.1 设计理念

**核心概念**：聚焦 · 洞察 · 机遇

招标雷达的Logo围绕"雷达扫描"的视觉隐喻，表达产品能够精准探测市场机遇的核心价值。

### 1.2 文字Logo方案

```
   ██████                       ██████
  ██    ██  招标雷达            ██    ██  BidRadar
   ██████        🔍             ██████
   
   方案A：中文+图标+英文组合
```

**设计说明：**

- **雷达图标**：简约的雷达扫描线条，代表信息探测
- **中文字体**：稳重大气，体现专业感
- **英文字体**：现代简洁，便于国际化
- **色彩**：蓝色为主色调，代表科技与信任

### 1.3 图形Logo方案

```
        ╭──────────────╮
       ╱   ＼       ／   ＼
      │    ◯────────◯    │
      │    │   探   │    │
       ╲   ／       ╲   ╱
        ╰──────────────╯
        
   方案B：雷达扫描图形
```

**设计说明：**

- 雷达圆形外框代表扫描范围
- 四条放射线代表探测信号
- 中间原点代表目标/机遇
- 整体简约，易于识别和记忆

### 1.4 推荐配色

| 用途 | 颜色 | 色值 |
|------|------|------|
| 主色 | 科技蓝 | #0066FF |
| 辅色 | 深空蓝 | #1A365D |

| 背景色 | 浅灰白 | #F7F9FC |

## 五、设计规范

### 5.1 字体使用

- **中文**：思源黑体 / 阿里巴巴普惠体
- **英文**：Source Sans Pro / Roboto

### 5.2 间距规范

- Logo周围保持至少高度50%的留白
- 文字与图形保持适当间距
- 按钮周围保持足够呼吸空间

### 5.3 使用禁忌

- 不能改变Logo的颜色（除黑白稿外）
- 不能拉伸或变形Logo
- 不能在复杂背景上使用（需加边框或阴影）
- 不能遮挡Logo的任何部分

## 七、总结

招标雷达的品牌视觉遵循以下原则：

1. **简洁有力**：信息传达清晰，不冗余
2. **科技感**：体现智能化和专业性
3. **可识别性**：独特的雷达元素易于记忆
4. **一致性**：各场景素材保持统一风格

---

**设计执行建议：**

1. 优先制作Logo和基础VI素材
2. 官网Banner可使用产品截图+设计模板
3. 社交媒体素材可使用模板快速生成
4. 保持视觉风格统一，定期优化迭代
