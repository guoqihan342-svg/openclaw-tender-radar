# 手机配置飞书Bot（5分钟）

## 步骤

### 1. 打开飞书APP
- 确保已登录飞书账号

### 2. 创建群聊
- 点击底部"消息"
- 右上角"+" → "创建群组"
- 群名: **招标雷达免费预览**
- 群介绍: 每日早8点推送精选政府采购商机
- 创建

### 3. 添加机器人
- 进入刚创建的群
- 点击右上角"···"（群设置）
- 找到"群机器人"
- 点击"添加机器人"
- 选择"自定义机器人"
- 名字: **招标雷达**
- 头像: 可选（可以用🎯）
- 点击"添加"

### 4. 复制Webhook地址
- 添加成功后会显示一个链接
- 格式: `https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxx`
- **长按复制这个链接**

### 5. 发送给我
- 把复制的链接发给我
- 我帮你配置到系统

### 6. 测试
- 配置完成后，我会发一条测试消息到群里
- 你确认能收到就行

**Q: Webhook地址太长复制不全？**
A: 点击"复制地址"按钮，或分段复制发给我

**Q: 可以稍后配置吗？**
A: 可以，但配置了才能自动推送日报
