## 3. 产品方案（冻结）

### 主赛道
**招投标 / 采购机会雷达**

选择理由：
- 输出容易标准化
- 日报/周报天然成立
- 付费逻辑清晰
- 本地自动化容易落地

### 数据来源
- 中国政府采购网 (ccpgp.gov.cn)
- 各省市政府采购网
- 完全公开数据，合法合规

### 产品形态
**每日自动推送的招标精选日报**

内容包括：
- 10条精选招标（标题、预算、地区、截止日、采购方）
- AI生成的推荐理由
- 分类统计和洞察
- 升级引导

### 收费模式

| 版本 | 价格 | 内容 |
|------|------|------|
| 免费版 | ¥0 | 每日3条 |
| 标准版 | ¥99/月 | 每日10条+周报 |
| 高级版 | ¥299/月 | 全量+定制+API |

### 获客渠道（全自动）
1. SEO内容站（5篇文章+落地页）
2. 知乎/小红书/即刻内容引流
3. 表单收集+自动跟进
4. 飞书/邮件交付

## 4. 技术方案（冻结）

### 技术栈
- **后端**: Python 3.12
- **数据库**: SQLite（MVP阶段，后期可迁移）
- **爬虫**: requests + BeautifulSoup
- **AI**: MiniMax API
- **部署**: Vercel/Netlify（免费）
- **定时**: crontab
- **通知**: 飞书机器人

### 核心流程（每日自动）
```
08:00 自动启动
  ↓
08:01 抓取昨日新增招标
  ↓
08:05 AI生成摘要和推荐理由
  ↓
08:10 生成精选日报
  ↓
08:15 推送给付费用户（飞书/邮件）
  ↓
08:20 执行自动转化跟进
  ↓
08:30 完成，等待明日
```
