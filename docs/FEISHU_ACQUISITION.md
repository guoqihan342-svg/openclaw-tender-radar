# OpenClaw 招标雷达 - 飞书社群全自动分发方案

## 原理

通过飞书机器人，将日报自动推送到：
1. **你创建的飞书群组** - 作为免费预览群
2. **加入的行业群组** - 被动曝光（需群主允许）
3. **用户的私聊** - 付费用户专属推送

**全自动，无需人工每天操作**

---

## 配置步骤

### 1. 创建飞书机器人

1. 打开飞书 → 工作台 → 应用管理
2. 创建自定义机器人
3. 获取 Webhook URL
4. 保存到环境变量：`FEISHU_WEBHOOK_URL`

### 2. 配置每日自动推送

编辑 `scripts/feishu_sender.py`:

```python
FEISHU_WEBHOOK_URL = "https://open.feishu.cn/open-apis/bot/v2/hook/xxxxxxxx"

# 推送目标配置
PUSH_TARGETS = {
    'free_group': '免费预览群',      # 每日3条免费
    'paid_users': '付费用户私聊',    # 每日10条完整
    'vip_users': '高级版用户'        # 全量推送
}
```

### 3. 创建免费预览群

**群名称**: 招标雷达免费预览群  
**群介绍**: 每日早8点推送3条精选政府采购商机  
**入群方式**: 公开可搜索  

**群内自动回复配置**:
```
关键词: "订阅"
回复: "感谢关注！标准版¥99/月，每日10条+周报。订阅链接: [payment page]"
```

## 进阶：加入外部群组

**策略**: 加入政府采购、招投标相关群组，设置自动转发

**注意事项**:
1. 先征得群主同意
2. 不要刷屏，每天最多1条
3. 内容有价值，不要硬广

**实现方式**:
```python
# 在 feishu_sender.py 中添加
EXTERNAL_GROUPS = [
    '政府采购交流群',
    'ToB销售联盟',
    '招投标信息共享'
]

# 每日推送时，同时发送到外部群
for group in EXTERNAL_GROUPS:
    send_to_group(group, daily_report_summary)
```

## 监控和优化

### 追踪指标

1. **群成员增长** - 每日新增多少人
2. **转化率** - 免费群→付费用户的比例
3. **活跃度** - 群内讨论热度
4. **退群率** - 监控是否内容质量下降

### 优化策略

| 指标 | 优化动作 |
|------|---------|
| 成员增长慢 | 在其他渠道推广群二维码 |
| 转化率低 | 优化预览内容质量 |
| 退群率高 | 减少推送频率或提升内容价值 |
